# smart-expense-tracker
A lightweight REST API to manage personal expenses, built with Python and FastAPI.

## Tech Stack
- *Framework:* FastAPI
- *Server:* Uvicorn
- *Testing:* Pytest & HTTPX
- *Data Persistence:* In-memory storage
